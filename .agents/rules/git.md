# Git & Pull Request 규칙

1. 모든 Git 커밋 메시지(Commit Message)는 **한국어**로 작성한다.
   - 예: `chore: ESLint 설정 제거 및 Biome 설정 추가`
   - 예: `fix: TypeScript 7 대응 타입 선언 및 구문 수정`
   - 예: `refactor: GameStatistics의 any 타입 제거 및 도메인 모델 적용`
   - 예: `style: Biome 포맷터 적용 (세미콜론 제거)`
2. Pull Request(PR)의 제목과 본문 설명 역시 모두 **한국어**로 작성한다.
